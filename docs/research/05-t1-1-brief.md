# T1-1 다중 무인기 동시 통제 — 다음 단계 브리프

정리일 2026-10-08. 주제 결정: `decisions/log/0002-해커톤-주제-t1-1-다중-무인기-동시-통제.md` (제안 상태).

## 이미 정해진 것
- 문제: T1-1 1인 다중 무인기 동시 통제 (Multi-UxV Control). 원문과 상세 설명은 `01-track-problems.md`의 T1-1 절.
- SC1·SC2는 하지 않는다. SC3 오리건은 자동 심사 대상. T3-2 CCA 중복 제출은 선택.
- 시연 중 인터넷 사용 가능(`decisions/log/0001`). 공개·가상 데이터만 사용.
- 기존 저장소 구조(T1-3 기준 모듈)는 바꿔도 된다.

## 문제 요구사항 (시트 원문 요약)
- 단일 운용자가 공중·지상·해상 이종 무인체계 3대 이상을 동시에 임무 부여·감시·통제.
- 운용자 인지부하를 줄이면서 임무 성공률 유지 또는 향상.
- 예시 방향: 임무 단위 추상화, 자율 임무 분산·역할 할당, 인지부하 모니터링·우선순위 알림, human-in-the-loop 지점, 인력 절감률·임무 성공률 측정.

## 심사
- 1차(3분 발표 + 2분 질의): 군 적용 가능성 30, 문제 적합성 25, 기술 구현 25, 창의성 20.
- 2차(5분): 임팩트·확장성 35, 글로벌 확장 25, 기술 난이도·차별성 20, 팀 추진력 20.
- T1 심사위원: 미군(1·2차), 프레리스쿠너 대표, 한국대드론산업협회 센터장, 한국해양대 교수(2차).
