# 실작전 탭 Implementation Plan (Part1-48)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 헤더에 `실작전` 탭(`#ops`)을 더한다. 시뮬레이션과 같은 화면·같은 실행인데 재생 막대가 없고(들어가면 ×1), 한 번도 탐지되지 않은 적은 보이지 않는다.

**Architecture:** cop-ui만 바꾼다. `LiveApp`이 두 탭에서 같은 WS 연결을 쓰고, 실작전이면 Frame을 `sensedFrame`으로 한 번 거른 뒤 `Screen`에 넘기며 `Screen`은 `ops`면 `RunBar`를 그리지 않는다. 탭이 `#ops`가 되는 순간 `postRun("/run/live?speed=1")`.

**Tech Stack:** React 18 + TypeScript, vitest, `scripts/qa` (Playwright 기반 화면 점검).

**Spec:** `docs/superpowers/specs/2026-10-11-ops-tab-design.md` (결정 0067)

## Global Constraints

- gateway·contracts·엔진·`contracts.gen.ts`는 바꾸지 않는다.
- 로직은 액션 파일 1개 = 함수 1개 = vitest, 80줄 이하. 화면 컴포넌트는 테스트 생략 가능(`modules/cop-ui/AGENTS.md`).
- TDD: 실패 테스트 먼저, 실패 확인, 구현, 통과(결정 0014).
- 색은 `theme.css` 토큰만. 새 CSS 없음.
- 기존 화면 점검(`scripts/qa/live.json` 등)의 선택자(`.runbar .play`·`.clock`·`.next`, `.status`, `.mk.vehicle`, `.mk.target`, `.card`)는 시뮬레이션 탭에서 그대로.

## Review Focus

1. 탭을 새로 고침 없이 바꿀 때(`location.hash`만 바뀜) WS 연결이 끊기지 않고 `LiveApp`이 다시 만들어지지 않아야 한다 → Task 2의 QA O3·O5가 hash만 바꿔 확인.
2. 실작전에 들어갈 때 실행이 ×10으로 돌고 있었어도 ×1이 된다 → 같은 `postRun` 요청이라 QA O6(멈춤에서 ×1)로 갈음.
3. 실작전에 있는 동안 적이 처음 탐지되면 바로 나타나야 한다 → Task 1 테스트의 `seen1`(first_seen_ms 있음)로 확인.
4. gateway가 꺼진 채 실작전에 들어가도 화면이 죽지 않는다 → `postRun`은 throw하지 않는다(기존 `runApi.test.ts`).
5. 실작전의 기체 메뉴·지목에 미탐 적이 나오지 않는다 → 걸러낸 Frame이 `boardView`·`seenTargets`로 가므로 Task 1 테스트로 충분.

시연 시각 근거(빈 입력으로 엔진 실측, 2026-10-11): boat1·boat2·boat3는 T+11:00에 나타나고 첫 탐지는 T+16:21(boat1·boat2), boat3는 T+18:00까지 미탐. 그래서 점검은 T+12:00(720000 ms)에서 세 척 모두 미탐.

`modules/cop-ui/src/features/live/sensedFrame.ts`:
```ts
import type { Frame } from "../../contracts.gen";
import { trackState } from "../board/trackState";

// 실작전 tab (decision 0067): the operator's screen shows only what our side knows, so an enemy no sensor has ever
// detected (track "never", the simulator's truth) leaves the Frame before anything draws it. Seen, RF-only, lost
// and struck targets stay.
export function sensedFrame(f: Frame): Frame {
  return { ...f, targets: f.targets.filter((t) => trackState(t, f.t_ms, null).k !== "never") };
}
```

`modules/cop-ui/src/features/nav/tab.ts` 전체:
```ts
export type Tab = "editor" | "live" | "ops";

// #ops is 실작전 (decision 0067): the simulation screen without the run bar and without never-detected enemies.
export function tabFromHash(hash: string): Tab {
  return hash === "#editor" ? "editor" : hash === "#ops" ? "ops" : "live";
}
```

```tsx
function LiveApp({ ops }: { ops: boolean }) {
  const { frame, connected } = useFrames(WS_URL);
  const [zone, setZone] = useState<Polygon | null>(null);
  // The zone is fixed once the operation exists; read it again only after (re)connecting to the gateway.
  useEffect(() => {
    if (connected) fetchZone().then(setZone);
  }, [connected]);
  // 실작전 (decision 0067): entering the tab runs the shared run at ×1, and its screen has no run bar to change
  // that; it shows only what our sensors have detected.
  useEffect(() => {
    if (ops) postRun("/run/live?speed=1");
  }, [ops]);
  const shown = useMemo(() => (ops && frame ? sensedFrame(frame) : frame), [ops, frame]);
  return <Screen frame={shown} zone={zone} status={connected ? "LIVE" : "연결 끊김"} ok={connected} ops={ops} />;
}
```
