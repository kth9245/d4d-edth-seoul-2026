> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 헤더에 `실작전` 탭(`#ops`)을 더한다. 시뮬레이션과 같은 화면·같은 실행인데 재생 막대가 없고(들어가면 ×1), 한 번도 탐지되지 않은 적은 보이지 않는다.

**Tech Stack:** React 18 + TypeScript, vitest, `scripts/qa` (Playwright 기반 화면 점검).

**Spec:** `docs/superpowers/specs/2026-10-11-ops-tab-design.md` (결정 0067)

`modules/cop-ui/src/features/live/sensedFrame.ts`:
```ts
import type { Frame } from "../../contracts.gen";
import { trackState } from "../board/trackState";

// 실작전 tab (decision 0067): the operator's screen shows only what our side knows, so an enemy no sensor has ever
// detected (track "never", the simulator's truth) leaves the Frame before anything draws it. Seen, RF-only, lost
// and struck targets stay.
export function sensedFrame(f: Frame): Frame {
  return { ...f, targets: f.targets.filter((t) => trackState(t, f.t_ms, null).k !== "never") };
}
```

```ts
// #ops is 실작전 (decision 0067): the simulation screen without the run bar and without never-detected enemies.
export function tabFromHash(hash: string): Tab {

}
```

```tsx
function LiveApp({ ops }: { ops: boolean }) {
  const { frame, connected } = useFrames(WS_URL);
  const [zone, setZone] = useState<Polygon | null>(null);
  // The zone is fixed once the operation exists; read it again only after (re)connecting to the gateway.
  useEffect(() => {
    if (connected) fetchZone().then(setZone);
  }, [connected]);
  // 실작전 (decision 0067): entering the tab runs the shared run at ×1, and its screen has no run bar to change
  // that; it shows only what our sensors have detected.
  useEffect(() => {
    if (ops) postRun("/run/live?speed=1");
  }, [ops]);
  const shown = useMemo(() => (ops && frame ? sensedFrame(frame) : frame), [ops, frame]);
  return <Screen frame={shown} zone={zone} status={connected ? "LIVE" : "연결 끊김"} ok={connected} ops={ops} />;
}
```
