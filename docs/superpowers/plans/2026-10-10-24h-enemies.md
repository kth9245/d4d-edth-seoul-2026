# 멸공 적 양동 침투·동적 대응 선택지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 멸공 작전에 적 4기(자폭 드론·UGV 2대를 실은 USV)를 넣고, 아군 드론 발견 시 바다·땅·공중 판단에 맞춘 동적 선택지를 낸다.

**Architecture:** 계약 `TargetKind` 3값 추가 → sim은 usv만 섬 우회에 더함 → runtime에 영역 판단 액션과 표적 기준 원 경로, `fleet_choices` 확장 → 멸공 생성 스크립트가 적·role·온톨로지를 만든다. 엔진 틱 순서는 그대로, `fleet_choices` 호출에 targets·land만 더 넘긴다.

**Tech Stack:** Python 3.12, pydantic 계약, pytest(-n), uv, scripts/ship.sh

**Spec:** `docs/superpowers/specs/2026-10-10-24h-enemies-design.md`

## Global Constraints

- `demo/scenarios/baengnyeong_night.json` 수정 금지. 매 ship 후 `scripts/smoke.py` 결과가 `5052 ticks, card ... at T+16:30, '근접 확인' switched 3 vehicles, moved d1,usv,ugv, operator_actions=1` 그대로.
- 멸공 JSON은 `scripts/make_coast_routes.py` 재실행으로만 바꾼다(결정 0035).
- 계약 변경은 `TargetKind`에 `drone`, `usv`, `ugv` 추가만. schema·`contracts.gen.ts`는 `scripts/gen_contracts.py`로만.
- 액션 파일 80줄 이하, TDD, 작업마다 worktree → `scripts/ship.sh` → `task.py done`.
- 등장: e_drone·e_usv T+11:00(660000 ms), e_ugv1·e_ugv2 T+23:00(1380000 ms, from_enemy e_usv).
- 집중 순찰 반경 800 m, 한 적기당 드론 1대.
- 선택지 문구: `"{x} → 이탈 지역 순찰({해안 이름})"`, `"{x} → 적기 {N} 발견 지점 집중 순찰"`, `"usv → 적기 {N} 추적({영역})"`, `"ugv → 적기 {N} 추적({영역})"`, `"대기"`. 영역 표기 공중/지상/해상.
- 시작 전 Part2-46(병렬 세션, 같은 생성 스크립트) main 반영 확인.

## Review Focus

- 적이 해안선 근처라 같은 표적이 바다↔땅으로 바뀜 → 선택지를 만들 때마다 지금 위치로 다시 판단(Task 3 테스트 `test_domain_follows_current_position`).
- 같은 적기를 두 카드에서 집중 순찰로 고름 → 두 번째 결정은 그 드론을 옮기지 않음(Task 5 `test_second_focus_on_same_target_is_ignored`).
