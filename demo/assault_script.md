# 발표 라이브 시연 대본 — 공격 작전 "해안 거점·무인장비 무력화"

결정 0074(라이브는 이 작전 하나), 0080(흐름), 설계 `docs/superpowers/specs/2026-10-11-assault-demo-scenario-design.md`.
작전 id `baengnyeong_assault`. 시각은 시뮬레이션 기준(T+)이고 실제 엔진으로 잰 값이다(`tests/test_assault_scenario.py`).

## 운용 방법
- 배속 **×30**으로 돌리고 장면마다 **재생/멈춤**으로 세워 설명한다('다음 사건' 버튼은 없다, 결정 0079).
- 전체 약 15분 30초 = ×30에서 약 31초. 설명까지 1분 남짓.
- 멈춰 있는 동안은 시뮬레이션 시간이 흐르지 않는다. **클릭(직접 조종·표적 타격)은 멈춘 상태에서** 해도 된다.
- 화면 머리줄의 적 수는 "적 3"으로 나온다(세는 말 없음).

## 기체와 거점 (모두 가상)
- 정찰 드론 r1·r2, 공격 드론 a1·a2(서쪽 바다 기지), 수상정 usv(서쪽 바다), 지상 로봇 ugv(처음부터 서쪽 해변 안쪽 육지)
- 거점 3곳: 북쪽 site_n, 남쪽 site_s, 숲속(가운데) site_f

## 꼭 지킬 것
1. **수상정은 서쪽 해변의 지도 빈 곳을 누른다.** 북쪽 해안으로 보내면 북쪽 거점 근처라 흐름이 꼬인다. 수상정을 고른 뒤 서쪽 해변 바로 안쪽 육지를 누르면 수상정이 해안선 바로 앞까지 가서 멈춘다(대기 Role이라 그 자리에 머문다). 표적 표시를 누르면 다른 메뉴가 열린다.
2. **표적 타격은 거점이 '보이는' 동안만 메뉴에 뜬다.** 정찰 드론이 위에서 감시하는 동안은 계속 보인다. 지도에서 정찰 드론이 멈춘 뒤에 누르면 된다.
3. **a1은 북쪽을 친 뒤 숲속을 친다.** r1은 북쪽이 파괴된 뒤에야 숲속으로 가므로(T+13:28) 순서가 꼬이지 않는다.
4. **오른쪽 결정 칸에는 거점 카드가 뜨지 않는다.** 버튼 없는 알림이라 바로 '지난 기록'으로 들어가서 "지금 결정할 것이 없습니다"가 보여도 정상이다. 발견 신호는 지도로 본다. 카드에 타격 버튼은 붙지 않는다(타격은 메뉴로만).
5. **찾으면 멈추고 바로 지목한다.** 거점을 찾은 뒤 ×30으로 2분 넘게(시뮬레이션 70분 넘게) 타격을 미루면, 정찰 드론 배터리가 귀환 기준에 걸려 숲속으로 못 간다.
6. 첫 거점이 파괴된 뒤부터 오른쪽 칸에 **"작전 결과"** 상자가 나온다: 무력화된 거점 이름과 "운용자 조작 N번(기체별 직접 명령이었다면 M번)". 마지막 장면에서 이 숫자를 짚는다. 대기 결정이 남아 있으면 안 나온다.

## 안전(하방) 말할 거리
- "타격은 사람이 고른 명령만 나간다. 사람 결정이 붙지 않은 타격 명령은 엔진이 기체로 보내지 않는다."
- "표적이 작전 구역 밖이거나 돌아올 배터리가 모자라면 사람이 골라도 엔진이 막는다."
- "해변 안전은 정찰 편대로 확인하고, 상륙은 사람이 결정한다."
