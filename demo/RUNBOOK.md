# 시연 절차 (5분)

## 사전 점검 (심사 30분 전)
1. 시연 노트북 전원·HDMI 연결, 화면 해상도 확인
2. `scripts/demo.sh` 실행 (AI API를 쓰면 `.env`의 키와 네트워크 연결 확인) → 브라우저 http://localhost:8000
3. 지도 배경·표적·경보가 보이는지 확인
4. 백업 영상 파일 위치 확인: `demo/backup.mp4`

## 순서
라이브 데모는 공격 작전 "해안 거점·무인장비 무력화" 하나로 한다(결정 0074). 작전 고르기에서 그 작전을 고르고, 배속 ×30 + 재생/멈춤으로 돌린다. 장면별 대본은 `demo/assault_script.md`.
| 시간 | 내용 |
|---|---|
| 0:00–0:30 | 문제 한 줄 소개 |
| 0:30–1:30 | 1부 계획(편집기): 작전 개요·AI 초안·저장 전 검사·온톨로지 (`assault_script.md` 1부) |
| 1:30–3:30 | 2부 실행(시뮬레이션 ×30): RF 단서→직접 조종→식별→승인→무력화, 적 무인 수상정, **결정 한 번에 공중·해상·지상 함께 타격** (`assault_script.md` 2부) |
| 3:30–4:30 | 해커톤 중 새로 만든 부분 (BUILT_HERE.md) |
| 4:30–5:00 | 다음 단계 |

## 실패 시
- 화면이 안 뜨면: 터미널 오류 확인 → `scripts/demo.sh` 재실행 (10초)
- 그래도 안 되면 백업 영상 재생

## 메모
- `demo/BUILT_HERE.md`에서 rebase 충돌이 나면 양쪽 행을 모두 남긴다.
