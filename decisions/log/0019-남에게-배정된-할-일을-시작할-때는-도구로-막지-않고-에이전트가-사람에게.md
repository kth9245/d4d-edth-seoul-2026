## 결정
2026-10-09 사람이 말한 것을 그대로 적는다. AI가 "new_action.py로 남에게 배정된 항목을 시작해도 '배정: 누구' 경고가 나오지 않는다"고 보고한 뒤의 대화.

사람: "이거 누가 시작했다 되어있으면 시작했다 알려야한다고 강제."
AI가 방법을 물음(남의 배정은 --take 필수 / 모든 시작을 채팅에 / 둘 다).
사람: "ㄴㄴ 그냥 채팅으로 알려주기만 하면돼. 정말 할까요 ? 라고 물어보면 되지"

(AI 해석)
1. `task.py`·`new_action.py`는 남에게 배정된 `예정` 항목의 시작을 막지 않는다(결정 0008: 누구든 가져갈 수 있다). 남이 `진행중`인 항목은 지금처럼 `--take` 없으면 거부한다.
2. 에이전트는 번호표 항목을 시작하기 전에(`task.py start`, 연결된 SPEC 행의 `new_action.py`) `task.py show <번호>`로 배정을 보고, 배정이 다른 사람이면 사람에게 "X에게 배정된 항목입니다. 정말 할까요?"라고 묻는다. 사람이 하라고 하면 시작하고, 사람에게 "채팅에 X에게 알려 주세요"라고 말한다(task.py는 채팅으로 보낼 수 없다).
3. 도구는 시작 뒤에 `참고: 배정: X — 채팅에 알리세요`를 출력한다. `new_action.py`도 같은 줄을 출력한다.

## 이유
- 사람은 도구가 막는 것보다 묻고 알리는 것을 원했다. 하위 항목으로 돕는 흐름은 그대로 자유롭다.

## 버린 대안
- 남의 배정은 `--take` 필수: 사람이 거절.
- 모든 시작·완료·막힘을 채팅용 한 줄로 출력하고 붙이기를 의무화: 사람이 고르지 않음.

## 영향
- `scripts/new_action.py`가 연결 항목의 배정이 남이면 `참고: 배정: X — 채팅에 알리세요` 출력(`tools/ledger.start_for_spec`이 항목을 돌려줌).
- AGENTS.md "할 일 기록" 절과 task 스킬에 2번 규칙.
