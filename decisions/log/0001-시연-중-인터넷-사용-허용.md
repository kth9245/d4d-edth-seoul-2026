## 결정
시연 경로에서 인터넷과 외부 API(공개 데이터 API, LLM API, 온라인 지도 타일 등)를 써도 된다.
POLICY.md 1번("시연은 인터넷 없이 동작한다…")을 대체한다.
단, 시연에 쓰는 외부 데이터는 로컬 캐시를 남겨 두고, 네트워크가 끊겨도 캐시로 시연을 이어갈 수 있게 한다.

## 이유
- 팀 결정(2026-10-08): 인터넷 사용 가능으로 정책 변경.
- 실시간 공개 데이터(ADS-B 항적, 위성 궤도, AIS, 뉴스 등)와 외부 LLM API를 쓸 수 있어 선택할 수 있는 문제 범위가 넓어진다(특히 T2 OSINT).

## 버린 대안
- 완전 오프라인 유지: 구현 안정성은 높지만 실시간 데이터·외부 모델을 못 써 T2 계열 문제를 사실상 배제하게 된다.
- 제한 없이 온라인 의존: 행사장 와이파이가 붐비면 1차 심사(5분) 중 시연이 멈출 수 있다.

## 영향
- POLICY.md 1번 문구 교체 필요(사람만 수정).
- gateway: 외부 API 호출 허용, 실패 시 캐시로 대체하는 경로 필요.
- cop-ui: 온라인 지도 타일 사용 가능, 기존 로컬 타일은 예비로 유지.
- 외부 API 키는 `.env`로만 관리(POLICY 4번 유지).
